# Inventario de Bebidas

Programa de inventario para un local que vende cervezas, sodas y aguas. Funciona en el navegador del celular o de la computadora y se puede agregar a la pantalla de inicio como una app.

**Abrir el programa:** https://poloxz111.github.io/Inventario/

## Notas

- Los datos de cada persona se guardan en su propio dispositivo (no hay servidor).
- Es un solo archivo (`index.html`) más el icono, el manifiesto y `sw.js` para que funcione como app y sin internet.
- Para cambiar algo: editar `index.html` y subirlo; la página se actualiza sola en 1 o 2 minutos.
